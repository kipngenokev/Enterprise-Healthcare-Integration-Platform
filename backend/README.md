# Backend

## Purpose

This directory contains the Java Spring Boot backend for the Enterprise Healthcare Integration Platform.

## Responsibilities

The backend is responsible for:

- Business logic
- REST API development
- Authentication & Authorization
- Database persistence
- Healthcare interoperability (FHIR / HL7)
- Integration with external healthcare systems
- Validation
- Security

## Technologies

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Maven
- Docker
