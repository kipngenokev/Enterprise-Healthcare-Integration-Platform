# System Context

## Purpose

This document describes the external users and systems that interact with the Enterprise Healthcare Integration Platform (EHIP).

## System Boundary

The Enterprise Healthcare Integration Platform is responsible for:

- Patient Management
- Billing
- Laboratory Management
- Pharmacy Management
- Reporting
- Authentication & Authorization
- Healthcare Interoperability

## Human Actors

- Receptionist
- Doctor
- Nurse
- Pharmacist
- Laboratory Technician
- Billing Officer
- Hospital Administrator
- System Administrator

## External Systems

- Insurance Platform
- Ministry of Health Reporting
- Laboratory Information System (LIS)
- ERP
- External EMR/HMIS
- FHIR Server

## Interaction Summary

The EHIP serves as the central platform through which hospital staff manage patient care and administrative operations while exchanging healthcare information with external systems using standardized interfaces such as REST APIs, HL7, and FHIR.
