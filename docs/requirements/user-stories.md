# User Stories

## Overview

The following user stories describe the expected interactions between stakeholders and the Enterprise Healthcare Integration Platform (EHIP).

---

# Receptionist

### US-001

**As a Receptionist**

I want to register a new patient

So that the patient can receive medical services.

---

### US-002

**As a Receptionist**

I want to update patient demographic information

So that patient records remain accurate.

---

### US-003

**As a Receptionist**

I want to search for existing patients

So that I can quickly retrieve their records.

---

# Doctor

### US-004

**As a Doctor**

I want to view patient records

So that I can make informed clinical decisions.

---

### US-005

**As a Doctor**

I want to review laboratory results

So that I can diagnose patients accurately.

---

### US-006

**As a Doctor**

I want to prescribe medication

So that patients receive appropriate treatment.

---

# Nurse

### US-007

**As a Nurse**

I want to update patient observations

So that patient progress is properly documented.

---

### US-008

**As a Nurse**

I want to view patient history

So that I understand previous treatments.

---

# Laboratory Technician

### US-009

**As a Laboratory Technician**

I want to receive laboratory requests

So that I can perform the required tests.

---

### US-010

**As a Laboratory Technician**

I want to submit laboratory results

So that doctors can review them.

---

# Pharmacist

### US-011

**As a Pharmacist**

I want to receive prescriptions

So that I can dispense medication.

---

### US-012

**As a Pharmacist**

I want to update medication inventory

So that stock levels remain accurate.

---

# Billing Officer

### US-013

**As a Billing Officer**

I want to generate invoices

So that patients can be billed correctly.

---

### US-014

**As a Billing Officer**

I want to submit insurance claims

So that the hospital receives reimbursement.

---

# Hospital Administrator

### US-015

**As a Hospital Administrator**

I want to generate operational reports

So that I can monitor hospital performance.

---

### US-016

**As a Hospital Administrator**

I want to manage departments and system settings

So that hospital operations remain organized.

---

# System Administrator

### US-017

**As a System Administrator**

I want to manage users and roles

So that access to sensitive information is controlled.

---

### US-018

**As a System Administrator**

I want to monitor integrations

So that connected healthcare systems continue operating reliably.

---

# Integration Module

### US-019

**As an Integration Service**

I want to exchange patient data using FHIR

So that healthcare systems remain interoperable.

---

### US-020

**As an Integration Service**

I want to receive HL7 messages

So that laboratory and hospital systems can communicate.
